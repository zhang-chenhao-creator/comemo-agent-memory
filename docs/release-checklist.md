# Release Checklist

Use this checklist before publishing the first public release.

- README first screen clearly explains what comemo is.
- Core Markdown-only wording is accurate: the core memory system is Markdown-only, and adapters are minimal bridge examples.
- Chinese filenames under `templates/zh-CN/comemo/` render correctly.
- All relative links point to existing files.
- Adapter status does not overpromise runtime behavior or full tool support.
- `SECURITY.md` exists.
- `.gitignore` includes basic secret defenses.
- `v0.1.0` tag is ready to publish.
