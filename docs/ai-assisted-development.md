# AI-assisted Development

comemo was designed, reviewed, and documented with assistance from AI tools, including ChatGPT and Codex.

AI assistance was used for tasks such as:

- clarifying project positioning
- reviewing documentation structure
- drafting and refining Markdown files
- checking consistency between English and Chinese materials
- proposing repository workflow improvements

Final decisions, repository maintenance, release responsibility, and public claims belong to the human maintainer.

AI tools are not listed as project maintainers or formal contributors. They are treated as development assistants.

# AI 辅助开发说明

comemo 在设计、审查和文档整理过程中使用了包括 ChatGPT 和 Codex 在内的 AI 工具辅助。

AI 辅助主要用于：

- 梳理项目定位
- 审查文档结构
- 起草和打磨 Markdown 文件
- 检查中英文材料的一致性
- 提出仓库工作流改进建议

最终判断、仓库维护、发布责任和公开表述由人类维护者承担。

AI 工具不列为项目维护者或正式贡献者，而是作为开发辅助工具使用。
