# Security

comemo is a Markdown template repository. It does not execute code, install binaries, or sync data.

Do not store secrets, API keys, passwords, private tokens, financial credentials, or highly sensitive personal data in comemo memory files.

If an agent proposes to write sensitive information into memory, reject the change or redact the content first.

# 安全说明

comemo 是 Markdown 模板仓库，不执行代码，不安装二进制文件，也不做后台同步。

不要把密钥、API key、密码、私有 token、金融凭据或高度敏感的个人信息写进 comemo 记忆文件。

如果 Agent 建议把敏感信息写入长期记忆，应拒绝或先脱敏。
