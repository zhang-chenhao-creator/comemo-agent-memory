# 基础安装示例

这个示例展示 comemo 安装后的推荐目录形态。它不是安装脚本，也不是必须照抄的真实用户配置。

## 推荐结构

```text
~/.codex/AGENTS.md
~/comemo/
|-- 偏好.md
|-- 目标.md
|-- 能力.md
|-- 经验.md
`-- 身份.md
<project-root>/AGENTS.md
```

## 三层职责

### 1. 全局层

位置：

```text
~/.codex/AGENTS.md
```

只放所有协作都应该稳定生效的硬规则、记忆沉淀流程、按需读取长期记忆的路由表。

不要把项目状态、实验数据、临时结论写进全局层。

### 2. 项目层

位置：

```text
<project-root>/AGENTS.md
```

只放当前项目的目标、事实边界、记录位置、工作方式。

项目事实、参数、数据、结果、结论、下一步，应写在项目目录内的记录文件中。

### 3. 长期记忆层

位置：

```text
~/comemo/
```

用于保存跨项目长期有效的信息：偏好、目标、能力、经验、身份。

长期记忆不应该默认全量读取。Agent 应按任务需要读取相关文件。

## 安装原则

- 安装前检查已有 `AGENTS.md`、`AGENTS.override.md` 和其他 Agent 原生记忆文件。
- 不静默覆盖已有文件。
- 如果需要替换，先展示路径、说明影响，并备份。
- 所有占位符都必须替换完成。
- 安装后读取目标文件，确认非空且没有残留 `{{...}}`。

完整流程见 `docs/agent-install.zh-CN.md`。
