# English Installed Tree Example

When `LANGUAGE=en`, both template content and comemo filenames use English.

```text
{{CODEX_HOME}}/
└── AGENTS.md

{{MEMORY_PATH}}/
├── preference.md
├── goals.md
├── ability.md
├── experience.md
└── identity.md

{{PROJECT_ROOT}}/
└── AGENTS.md
```

Recommended defaults:

```text
~/.codex/AGENTS.md
~/comemo/
project-root/AGENTS.md
```

Cross-platform examples:

```text
Windows: C:\Users\<user>\.codex\AGENTS.md
macOS: /Users/<user>/.codex/AGENTS.md
Linux: /home/<user>/.codex/AGENTS.md
```
